## 2026-09-20 产品开发收尾

本轮不以重试某批新闻作为开发目标。按文档 8.1–8.7、18.3 与 19.3–19.5 核对实际实现，补齐如下产品流程：

| 文档范围       | 实现与使用入口                                                                                                                    |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 规则入口与解释 | 来源／分类／视图右键打开已有规则或预填未保存规则；条目详情展示实际发布版本、命中／覆盖关系并跳转来源规则。                        |
| 标签与 List    | 订阅管理标签列、筛选与批量增删；分类／List 辅助选源；List 使用后台持久的所有者 ID、完整度、修订和同步时间，unknown 不伪装零成员。 |
| 预设           | 补齐 Topic 入口、模板版本追踪、升级对照、替换／追加与替换确认；私人 Prompt 不被自动升级覆盖。                                     |
| 试运行         | 显式模型试运行复用正式 Codex／千问执行链、长文分块与引用校验；对照已发布结果与草稿结果，只写用量账本。                            |
| 显示动作       | 语言指令进入单篇及长文实际模型 Prompt；摘要按字素限制长度，原文引用保持不变。                                                     |
| 发布与回退     | 四类发布影响计数、历史发布只读比较；确认后复制历史版本为草稿，正常保存和生成新发布。                                              |
| 智能阅读       | 同域智能／原始切换；默认混合独立保留项与 Story，隐藏／待处理／失败独立入口，稳定序号与显式刷新。                                  |
| 阅读状态       | 固定快照计数、当前计划来源覆盖、真实运行状态、保存时区、下次启动、ready_by 与 poll。                                              |
| Story 纠错     | 拆出独立项、合并／拆分撤销恢复身份、旧链接可追溯；跨批更新可撤回旧结论，混合发布修复不放宽新策略。                                |
| 配置保护       | 失效分类待修复与前后端发布保护；公开模板默认去除私人身份并停用，完整私人备份须主动选择。                                          |
| 旧规则兼容     | 保留 cloud/local；旧新条件动作对照；官方规则只读；本地规则只有新发布成功且旧规则未变化才可按选择停用。                            |
