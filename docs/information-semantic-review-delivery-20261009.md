本次依据《Folo_标签系统审查与规则优化_2026-10-08.md》及其引用的独立验收样本，完成分类、阅读策略、事件归属、关注提示和历史错误的联动修正。源码基线为 `8840855ab`，验收时间为 2026-10-09（Asia/Shanghai）。

## 已实现的行为

| 反馈                           | 当前行为                                                                                                                                         |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| 分类、去重、综述范围不同       | 7 条阅读规则共用 Blockchain、X、AI、个人成长和创业的动态分类范围；每个策略字段分别按规则优先级合并，避免早期展示策略覆盖后续专用动作。           |
| 模型建议隐藏或标签未知导致误伤 | 隐藏须有明确阅读规则或有据专用去重；普通条目与长文共用实质贡献判断，教程、数据、分析和经验正证与整篇噪声冲突时保留未知及解释。                   |
| 待定策略被误认为缺正文         | 分别投影材料覆盖、原始语义评估覆盖及待定策略字段；可读但规则待定的条目保留独立，实际缺材料才进入 `needs_context`。旧记录无法推断的字段保持未知。 |
| 只有打开列表才分类             | 支持“启用后新增内容”及“当前列表加载内容”两种分类模式；首次收到时间独立保存，后续补正文不会把旧材料变成新内容。                                   |
| 重要信息与独立展示捆绑         | 重要/紧急关注独立于去重和原文展示；关注对象、别名和期限窗口可在原生公共设置维护，注意力变更不重跑语义模型。                                      |
| 只能比较相邻综述版本           | 详情按实际已读回执与正在查看的不可变版本累计展示新增、移除及修订事实；读态在内容就绪后记录，旧响应不能标读新版本。                               |
| 别名、日期和长文召回不足       | 别名须有原文等价证据，事件时间使用发生区间，统计周期须有明确日期；全文比较仅对有价值候选启用。                                                   |
| 多事件文章整篇混入单个综述     | 事实携带事件提及归属并校验原文片段；没有主事件的多事件文章也可分别参与对应综述，生成只使用选中事件的事实和摘要。                                 |
| 旧错误继续通过缓存返回         | 精确隔离指定正文版本和当前决定指针，保留旧决定与审计记录，阻止对应缓存复用；命令默认只预览，应用须暂停计划、等待工作完成并创建新备份。           |

有界全文比较最多读取每篇 60,000 字符，每批最多 2 组不同长文对、总计 120,000 字符；保留原有每批最多 3 次候选比较调用、每次 8 个候选，不添加重试循环。缺失图片、字幕、音频或外链材料仍保持未知，本次没有加入 ASR 或视频理解。
