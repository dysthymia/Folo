# 增强去重与增量综述：第三阶段实现

本阶段接在[语义标签](./information-semantic-tags.md)和[事件登记](./information-events.md)之后，复用当前去重、Story 版本、引用和人工纠错机制。只有获授权的当前未读条目进入日常处理；已读材料仍仅作为 24 小时参考，不补抓、不改读态。

## 候选召回与折叠

候选取原文本通路、确认事件 ID、原文支持的主体/动作/对象及版本、轮次、官方引用、明确发生时间/时区或完整统计起止区间通路的并集。来源、规则范围、处理目标、已判关系及时间资格先于候选预算过滤。每八对候选预留两个文本名额，事件提及或标签缺失不会阻断原文本召回。

真实 Store 只提供当前发布指针对应的确认归属和该篇决定保存的原始身份。候选事件、失效决定及人工移出不提供确认事件 ID；人工移动不能把目标事件的展示身份反写成当前原文证据。身份通路还逐字段核验连续原文引用；实体名称及别名只在当前档案有原文支持时用于候选召回，不改写事件身份，也不凭名称相似证明重复。明确发生时间按可核验时区处理，完整统计区间按起止边界隔离；已知版本、轮次、时间区间及官方引用冲突不能靠共同标签跨过。

同事件仅用于召回。廉价通路保留最多 4,000 字符的正文片段；每批最多 8 对候选，其中至多 2 对可升级到已有完整正文核对，单篇上限 60,000、整批去重正文上限 120,000 字符。同批同条目正文去重，优先保留完整版本；升级优先有据的事件/身份召回或文字相似度至少 0.72 的完整候选。缺正文、超限或未升级的候选保持证据不足，不能把截断前部证明为全篇重复，也不会为升级暗中补抓历史内容。

保留 48 小时比较窗口、逐字证据及 `equivalent / first_contains_second / second_contains_first / different / uncertain` 比较器。缺失图像、引用、串文、链接或媒体材料不能证明全文重复。评测、新增事实和反证经比较后独立保留；人工保留继续覆盖自动隐藏。

扫描记录绑定当前召回元数据水印。迟到的事件登记或当前归属变化使旧扫描重新可用，但不删除已判全文关系。召回元数据不进入比较模型或全文证据缓存地址，不因索引变化重复支付同一全文比较。

## Story 的信息增量

模型调用前先核对已发布事实、摘引及已有成员的完整材料。当前成员已进入同一 Story 时跳过；新材料只有被已有完整原文或连续全篇摘引覆盖，且上下文材料也一致时，才能证明没有信息增量。摘要、标题相似或有限事实子集均不能证明全篇没有新增限制或反证。

新建 Story 要求至少两份独立、已获许可的信息贡献；两份 URL、不同抽取措辞或不同事实分类不能把同一转载变成多来源证据。发布时再核对模型实际引用的成员。没有独立贡献的材料继续使用原有阅读入口，不因跳过 Story 而隐藏或改读态。

有新事实时继续按当前许可证据更新，旧事实、依赖关系及原文引用可以保留。Story 更新缓存绑定原 Story ID、当前 revision 和完整派生材料，人工修订之后不能复用针对旧版本生成的草稿。单篇事件不强制生成 Story。多事件文章按 `eventMentionIndex` 只提供当前已确认事件片段的许可事实；同一文章可服务不同事件，每篇 Story 仍核验自己的成员、关系及原文摘引。分析、教程、周报的独立阅读入口保留，不能因为贡献了部分事实而折叠整篇。

## 自实际已读版本累计的差异

Story 已读回执记录用户实际阅读的不可变 `revision`。冻结列表或旧链接标读只能标记该版本，不能把用户尚未看到的最新实质修订一起标为已读。比较基线选择实际读过的最高实质版本及其最新回执修订；后来打开旧链接不会让基线倒退。手动标未读只清理该 Story 回执，不改变成员原文读态，收藏继续按稳定 Story ID 保存。

阅读详情返回 `readDelta`，包含 `fromRevision / toRevision / currentRevision`、相应实质版本、`substantiveUpdateCount` 和 `added / removed / revised` 事实及引用。差异直接比较已读基线与本次查看版本，跨过多次更新仍累计展示；引用换代、事实编号变化或纯展示改动不会重复提示。只有稳定事实 ID 可对应时才标作修订，否则分别展示新增与移除，不猜测反证语义。

`scope` 区分 `first_read / since_read / up_to_date / older_version / baseline_unavailable`。没有已读回执才是首次阅读；历史基线缺失时明确报告不可比较。该投影不调用模型、不自动修改回执；失效、撤回或不可访问来源的旧事实可说明移除范围，但不重新暴露原文摘引。

## 正文版本修复

仅标题变化会产生新输入版本。完整原文、来源身份、上下文、已许可事实、事件身份和规则版本均未改变时，修复只迁移引用到当前正文版本，保留句段、事实、引用 ID、Story ID 与不可变旧 revision，无需模型。生成的修复 revision 不增加实质版本，因此已读和收藏保持。

实际正文、事实许可、上下文或规则变化仍走现有修复。调用模型前先核验当前事件归属、手工排除和所选事件事实片段边界；人工拆开的同名事件不能凭旧身份自动拼回。新草稿最终仍经过当前决定指针、原文片段和排除约束校验。

## 验证与后续

使用假模型和 SQLite 验证召回、全文比较、增量更新、引用迁移与阅读状态。回归覆盖低文字重合的同事件、最近材料不同而更早材料重复、文本预算、48 小时窗口、24 小时参考、迟到登记、人工保留/拆分、图片和链接不完整、纯转载零综合、新事实保留旧引用及旧版本缓存隔离。

本说明记录源码与本地验证，不据此声称已部署、已启用真实账号规则、已请求真实模型或已执行历史重跑，也不代表已完成真实来源验收。当前已支持有据的多事件逐事实归属及实际已读版本累计差异；任意事件关系、未读媒体理解、更广泛别名推断和超过正文预算的全文去重仍不在该能力范围内。
