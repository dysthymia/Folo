## 二、真机数据核对抓到一个真 bug（提交 0ade0da6c）

用业务库 `VACUUM INTO` 副本 + 源码 harness（沿用 9-21 的 `/tmp/folo-dedupe-offline/roles.mts` 套路）
核对，发现 **`restored` 角标永远不会出现**：

`roles()` 里恢复分支写成「当前角色是 hidden 或 merged 才覆盖成 restored」，但恢复覆盖本身已经让
`entryHidden()` 返回 false —— **同一次投影里根本不会为它产生 hidden 角色**，那条判断对 hidden
永不成立。结果：点「恢复」条目确实回到列表了，但「已手动恢复」角标看不到（`merged` 那条路正常）。

修法：改判「若没有这次恢复**是否会被隐藏**」（`entryHidden(undefined, decision)`）。

**踩到的坑，下轮直接用**：

- `setOverride` 读写的表是 **`processing_source_item_overrides`**（键 `source_key+item_id`），
  不是 `processing_entry_overrides`（那张表里是空的）。`overrides()` 会把**全部 input** 都列出来，
  没有行的条目填 `mode:"automatic", revision:0`。
- `setOverride` 带乐观锁，`expectedRevision` 必须取该条目**当前真实 revision**（不能假定 0），
  否则 `AutomationError: revision_conflict`。真机目标 seq=4437 的 revision 是 2。
- 覆盖率会骗人：我先跑 `pnpm --filter Folo run build:web` 被 safe-delete 拦了（`rm -rf out/web` 要
  批量确认），改成 `mv out/web out/.web-pre-<ts>` 再 `WEB_BUILD=1 pnpm exec vite build`。
  另外 `cross-env` 不在 PATH，要用 `pnpm exec` 或直接给环境变量。
- **`turbo run lint` 加 `--filter` 会静默跳过根包任务**（`//:lint`、`//:format:check`），
  看起来"通过"其实没跑。要跑真质量门就别带 `--filter`。
- 本地 locale JSON 有 `recursive-sort` 规则，**键必须递归有序**，插新键后要
  `npx eslint --fix locales/app/*.json`。
